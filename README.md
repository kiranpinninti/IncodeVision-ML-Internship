# IncodeVision ML Internship

This repository contains my Machine Learning projects completed as part of the IncodeVision Machine Learning Internship Program.

## Completed Tasks

### Task 01 - Data Cleaning and Visualization

Performed data cleaning and exploratory data analysis on a house price dataset using Python.

Technologies:
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

Key work:
- Missing value analysis
- Duplicate detection and removal
- Statistical analysis
- Data visualization
- Correlation analysis

### Task 02 - Linear Regression

Built a Linear Regression model to predict house prices using property features.

Technologies:
- Python
- Pandas
- Matplotlib
- Scikit-learn

Key work:
- Data preprocessing
- Categorical feature encoding
- Train-test split
- Linear Regression
- Model prediction
- MSE evaluation
- R² evaluation
- Actual vs Predicted visualization

## Results

Task 02 achieved an R² score of approximately **0.653** on the test dataset.
